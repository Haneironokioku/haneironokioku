# 羽根いろの記憶 公式サイト

このフォルダの中身を、そのまま GitHub のリポジトリに入れれば公開できます（GitHub Pages：main ブランチ / root）。

```
haneiro-site/
├─ index.html            … ホームページ
├─ .nojekyll             … GitHub Pages 用（消さないでください）
├─ images/               … ホームページの画像を入れる場所（下の表の名前で）
└─ games/
   ├─ rhythm/            … 空地幻想 リズムバトル
   │   ├─ index.html
   │   ├─ bgm.dat        … バトル曲（暗号化済み。単体では再生できません）
   │   ├─ clear_voice.wav… クリアボイス（VOICEVOX:ずんだもん）
   │   ├─ pv.mp4         … PV動画（76.7秒・1280×720・音声なし）。差し替えるときはこの名前で
   │   └─ mascot.png     … ★マスコット画像をこの名前で入れる（入れるまでは仮のはにわ）
   └─ haniwa/            … はにわのぼうけん
       └─ index.html
```

画像は **決まった名前で `images/` に入れるだけ** で表示されます。入れていない所は、今のグレーの仮枠が表示されます。

## リズムゲームの素材（games/rhythm/）

**PV動画：pv.mp4**
- 長さ：**約75秒（1分15秒）以上**。ゲームは曲の頭と同時に動画を再生し、最後のノーツ（74.2秒）の0.5秒後にクリア演出に入って、そこで動画を止めます。長い分には問題ありません。短いと最後のコマで止まります。
- 形式：MP4（H.264）、1920×1080 か 1280×720。音声は使いません（消音で再生）。
- 容量：**50MB以下**推奨（GitHub は 100MB を超えるファイルを置けません）。
- スマホ縦向きでは左右が切れるので、大事なものは中央寄りに。

**マスコット画像：mascot.png**
- PNG（背景透過）、縦長でおすすめ **400×500**。
- 足元（接地する所）を画像の下端に、キャラは左右中央に。上は吹き出しが出るので少し余白があるとよいです。

## 公開前に書き換えるところ

- `index.html` の `[ ]` の部分（料金、納期、英語タイトル、SNSのURL など）
- `index.html` の `og:image` の URL（`ユーザー名.github.io` を自分のURLに）
- お問い合わせフォーム：GitHub Pages だけでは送信できません。Formspree などで送信先URLを作って、`index.html` の一番下にある `FORM_ENDPOINT = ""` の `""` の中に入れてください。入れるまでは「準備中」の案内が出ます。
- バトル曲は再配布防止のため、暗号化した `bgm.dat` にしてあり、ゲームの中でだけ元に戻して再生します。リポジトリから落としても曲としては再生できません。**元の mp3 はリポジトリに入れないでください。**（録音などで音を取ることまでは防げません。購入した曲の規約に「Webゲームでの使用」が含まれているかは確認してください）
